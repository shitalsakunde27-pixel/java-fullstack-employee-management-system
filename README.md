# Employee Management System

## Project Description

The Employee Management System is a Java Full Stack web application developed to manage employee records efficiently.

## Technologies Used

- Java
- Spring Boot
- React.js
- MySQL
- REST API
- HTML
- CSS
- JavaScript

## Features

- Add Employee
- View Employee
- Update Employee
- Delete Employee
- Employee Management

## Project Type

Java Full Stack Web Application

## How to Run

1. Download the project ZIP file.
2. Extract the ZIP file.
3. Open the backend project in Eclipse or IntelliJ IDEA.
4. Configure the MySQL database.
5. Run the Spring Boot application.
6. Run the frontend application.
